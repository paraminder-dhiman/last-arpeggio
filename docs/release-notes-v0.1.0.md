The first release of The Last Arpeggio · play songs on the guitar in *The Last of Us Part II*, from any MIDI file.

**Download** `TheLastArpeggio-v0.1.0-windows.zip` below, unzip it anywhere and run `TheLastArpeggio.exe`. Windows may warn that the app is unrecognised, because it isn't signed · click **More info**, then **Run anyway**.

### What's in it
- Import any MIDI file · pick a part, with the melody suggested for you
- Melody, Chords or Both modes
- Fits songs to the guitar's range and fixes spots that are too fast (thin out, slow down or keep)
- Plans the wheel route with the fewest switches
- Preview through your speakers, play at 50 to 100 percent speed
- Now playing screen with the live wheel, note and bar
- Stop key you can set to any key or combo (F8 by default)
- Pick the game's window from a list
- Light and dark themes
- Two public-domain example songs: Greensleeves and Ode to Joy

### First run
Open **Settings**, pick the game window, then **Test the wheel** with the game's guitar on screen. If any strum misses, adjust **Flick distance**. The [README](https://github.com/paraminder-dhiman/last-arpeggio#readme) has the full guide.
